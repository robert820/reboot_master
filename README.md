# 重啟大師 (Reboot Master)

<h2 id="繁體中文">繁體中文</h2>

**重啟大師** 是一款輕量、安全且功能強大的 Windows 電源與啟動管理工具。專為日常使用與系統維護（包含 WinPE 環境）設計。

### 主要功能
- **一鍵重啟至 BIOS/UEFI**：無需狂按鍵盤，直接進入主機板設定。
- **無痕安全模式**：提供一般與含網路的安全模式。進入安全模式後，第二次重新開機即自動恢復正常，不用擔心陷入安全模式無限輪迴。
- **進階開機選單**：快速進入 Windows 修復環境 (WinRE) 與進階啟動設定。
- **安全防護控制**：一鍵開啟/關閉測試模式、停用驅動程式強制簽章，以及記憶體完整性（適合進階玩家或開發者）。
- **隨身碟快速啟動 (PE支援)**：自動偵測並設定由 USB 隨身碟開機。

### 使用方法
1. 於 Releases 頁面下載最新版本的 `reboot_master.exe`。
2. 點擊右鍵「以系統管理員身分執行」（進階重啟功能需系統權限）。
3. 點選介面中對應的功能卡片即可執行。

<h2 id="简体中文">简体中文</h2>

**重启大师** 是一款轻量、安全且功能强大的 Windows 电源与启动管理工具。专为日常使用与系统维护（包含 WinPE 环境）设计。

### 主要功能
- **一键重启至 BIOS/UEFI**：无需狂按键盘，直接进入主板设置。
- **无痕安全模式**：提供一般与含网络的安全模式。进入安全模式后，第二次重新开机即自动恢复正常，不用担心陷入安全模式无限轮回。
- **高级开机菜单**：快速进入 Windows 修复环境 (WinRE) 与高级启动设置。
- **安全防护控制**：一键打开/关闭测试模式、停用驱动程序强制签章，以及内存完整性（适合高级玩家或开发者）。
- **U盘快速启动 (PE支持)**：自动侦测并设置由 USB U盘开机。

### 使用方法
1. 于 Releases 页面下载最新版本的 `reboot_master.exe`。
2. 点击右键「以管理员身份运行」（高级重启功能需系统权限）。
3. 点击界面中对应的功能卡片即可执行。

<h2 id="english">English</h2>

**Reboot Master** is a lightweight, secure, and powerful power and boot management tool for Windows. It is designed for daily use and system maintenance, including WinPE environments.

### Key Features
- **Reboot to BIOS/UEFI**: Boot straight into your motherboard settings without mashing keyboard keys.
- **Seamless Safe Mode**: Supports Minimal and Network Safe Mode. Automatically returns to normal mode on the second restart, preventing infinite Safe Mode loops.
- **Advanced Boot Options**: Quickly enter the Windows Recovery Environment (WinRE) and advanced startup settings.
- **Security Control**: Easily toggle Test Mode, Driver Signature Enforcement, and Memory Integrity (for advanced users and developers).
- **Quick USB Boot**: Automatically detects and sets the system to boot from a connected USB flash drive.

### How to Use
1. Download the latest `reboot_master.exe` from the Releases page.
2. Right-click and "Run as Administrator" (system privileges are required for advanced boot modifications).
3. Click the corresponding action card in the app to execute.
